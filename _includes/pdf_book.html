{%- comment -%} pdf_book.html — an "open book" PDF reader for MinDoc. Renders a PDF (client-side, via PDF.js) as a two-page spread with prev/next controls. Works on GitHub Pages with no build step. Usage: {% include pdf_book.html src="/assets/pdf/my-source.pdf" %} Or, as used by media_next.html / image_description.html, pass a media element's path: {% include pdf_book.html src=element._path %} Parameters: src (required) path or URL to the .pdf file. If it points inside the site (starts with "/"), the site base path is prepended so it resolves on GitHub Pages. Absolute http(s) URLs are used as-is. id (optional) a unique id for this viewer. Defaults to an auto-incremented value so multiple viewers can coexist on a page. start_page (optional) 1-based page number to open on. Defaults to 1. Values outside the document's range are clamped. In two-page (spread) mode the viewer opens on the spread that contains this page. {%- endcomment -%} {%- assign base_path = site.baseurl | default: site.github.baseurl -%} {%- assign src = include.src -%} {%- assign start_page = include.start_page | default: 1 -%} {%- comment -%} Resolve the source URL against the site base when it's a local path. {%- endcomment -%} {%- if src contains '://' -%} {%- assign resolved_src = src -%} {%- else -%} {%- assign resolved_src = base_path | append: src -%} {%- endif -%} {%- comment -%} Give each viewer a unique id so several can live on one page. {%- endcomment -%} {%- if include.id -%} {%- assign viewer_id = include.id -%} {%- else -%} {%- capture _n -%}{% increment pdf_book_index %}{%- endcapture -%} {%- assign viewer_id = "pdf-book-" | append: _n -%} {%- endif -%}
